# Lecture 07 · Typography & Visual Design

**Web Designing** · Module: CSS · Technoledge Eduresearch Pvt. Ltd. · Trainer: Gourav Kashiv

## Six things to remember

1. Pick a type scale, then stick to it.
2. Body text: 4.5 : 1 contrast, line height ~1.6.
3. Spacing from a fixed scale, never random.
4. Hierarchy = size, weight, colour, space.
5. Tokens: define in :root, use with var().
6. Silent bugs need deliberate tests.

## How to use it

1. **Download:** green **Code** button → **Download ZIP**, or `git clone https://github.com/gouravkashiv7/web-design-lec-07.git`
2. **Open** the folder in VS Code.
3. **Run** any `.html` file: right-click → **Open with Live Server**.
4. **Don't edit the originals.** Copy the `project/starter/` folder and work in your copy.
